# UniCon — Landing Page (النسخة العربية)

موقع تسويقي متجاوب مع الهاتف والحاسوب، بدون مكتبات JavaScript أو أدوات بناء أو خادم. شعار UniCon المعتمد موجود داخل assets/unicon-logo.svg.

## التشغيل

1. فك ضغط الملف المضغوط.
2. افتح `index.html` في متصفح Chrome أو Edge أو Firefox.
3. يعمل الموقع مباشرة حتى دون اتصال بالإنترنت، باستثناء خط Cairo الذي يُحمّل من Google Fonts عند وجود الإنترنت (مع بدائل محلية).

## تفعيل التواصل

افتح `config.js` واملأ البيانات الرسمية الفعلية:

```javascript
window.UNICON_CONTACT = {
  email: "sales@YOUR-APPROVED-DOMAIN.COM",
  phone: "+970XXXXXXXXX",
  whatsapp: "+970XXXXXXXXX",
  instagram: "https://www.instagram.com/YOUR_OFFICIAL_ACCOUNT/",
  facebook: "https://www.facebook.com/YOUR_OFFICIAL_PAGE/"
};
```

**القيم الواردة أعلاه أمثلة غير حقيقية**. لا تنشرها. ترك القيمة فارغة يعرض وسيلة التواصل بوصفها غير مفعّلة. يتحقق كود الصفحة من تنسيق المدخلات ويعرض القنوات الصحيحة كرابط قابل للضغط.

## النشر

ارفع ملفات المجلد كما هي إلى مسار الويب المرغوب (مثل `/unicon/`) على خادم Universe، أو إلى خدمات استضافة الصفحات الثابتة. لا يلزم Backend. الصفحة لا تجمع أي بيانات شخصية بنفسها، ولا تستخدم كوكيز تحليلات أو خدمات تتبع.

## الملفات

- `index.html` صفحة الموقع باللغة العربية RTL
- `styles.css` تصميم متجاوب وتأثيرات الحركة
- `script.js` القائمة على الهاتف، الحركة، وتفعيل روابط التواصل
- `config.js` إعداد بيانات التواصل
- `assets/unicon-logo.svg` الشعار المعتمد
- `assets/favicon.svg` أيقونة التبويب

## قبل النشر

- تأكيد بريد المبيعات والهاتف والواتساب وحسابات التواصل الرسمية.
- اعتماد النصوص والخصائص المتاحة حاليًا ومراجعة شروط الأسعار والموافقة على الرسائل الترويجية.
- مراجعة الصفحة على الهاتف والحاسوب وإجراء اختبار الروابط.
- إذا أضيفت أدوات تحليلات مستقبلاً، يجب تهيئة سياسة الخصوصية وأي آلية موافقة مطلوبة.
